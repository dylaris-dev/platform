# Fonts

Self-hosted copies of Google Fonts (latin subset, woff2), fetched from
fonts.google.com on 2026-10-25 so the build no longer downloads them: a failed
fetch of next/font/google broke the Core image build twice that day. Each
family is licensed under the SIL Open Font License 1.1, see the OFL-*.txt file
next to it. The "Variable" files carry the whole weight axis in one file.
